Maven Coordinate Finder

IntelliJ IDEA plugin · Apache-2.0 · Free

Search Maven coordinates without leaving the IDE. Search by keyword, groupId:artifactId, or a fully-qualified class name; list every published version; copy a ready-to-paste Maven or Gradle snippet.

Features

  • Search by keyword, Maven coordinates, or fully-qualified class name.
  • Every published version, read from the authoritative maven-metadata.xml.
  • Copy as Maven XML, Gradle Groovy, Gradle Kotlin DSL, or plain coordinates.
  • Class-name results are verified against actual jar contents, not just a search index.
  • English and Chinese UI that follows the IDE language.
